One line, 1 to 240 characters, in the voice of the Moon replying at last to the
wishes, howls and late-night promises of everyone staring up at it.

## Run

```sh
node main.ts
```

`main.ts` writes the entry (84 characters, within the 240-character cap) to
`/output/entry.txt`.

## Entry

> You promised to change at 3 a.m. again. I believed you the first four billion times.

The Moon answers a late-night promise directly: it has heard the same promise
for four billion years, believed it every time, and is still waiting. The turn
— the sheer scale of the believing — lands in the last words.
